# Vecka 1 — Orientering och setup

## Mål
Skapa reproducerbar arbetsmiljö för Python och R, lära sig Git-flödet och planera veckorutinen.

## Arbetsmoment
1. Installera Python 3.11+ och R, samt valfri editor (VS Code/RStudio).
2. Skapa virtuell Python-miljö och installera `requirements.txt`.
3. Kör vecka 1-notebooken och kontrollera bibliotek och mappar.
4. Kontrollera R: `Rscript --version` och `Rscript -e "sessionInfo()"`.
5. Skapa branch, commit och push enligt `git_workflow.md`.
6. Skriv en kort fredagssammanfattning i rapportmallen.

## Definition of done
- [ ] Python och R fungerar lokalt
- [ ] Notebook körs utan fel
- [ ] Projektstruktur och Git-status verifierade
- [ ] Första commit pushad till GitHub
- [ ] Kort reflektion dokumenterad
